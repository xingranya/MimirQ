# 见外传媒知识库前端重构发布与回滚说明

## 发布范围

本次发布只调整 Web 前端及其测试、品牌资源和规格文档，不包含数据库迁移，不修改内部 API 路径、事件名、缓存键、部署名称或 `mimirq` 数据标识。

主要变化：

- 用户可见品牌统一为见外传媒知识库，头像标志统一为 `S`。
- 采用中性背景、单一主色、6px/8px 圆角和轻量边界的扁平视觉系统。
- AppShell、侧栏滚动和展开状态跨路由保持，主导航收敛为四组。
- 首页只保留欢迎信息、数据集范围、主输入和更多设置入口。
- SSE 继续兼容 `event`、`citations`、`token`、`done`、`error`，并支持答案增量渲染。
- 设置页重组为五个任务组，增加搜索、高级配置折叠、脏状态和固定保存栏。
- 知识库、历史、图谱和管理页迁移到统一视觉系统。

## 发布前门禁

在 `web/` 目录依次执行：

```bash
pnpm ui-check
pnpm lint
pnpm typecheck
pnpm test
PLAYWRIGHT_CHANNEL=chrome PLAYWRIGHT_USE_PROD_SERVER=1 PLAYWRIGHT_REUSE_BUILD=1 pnpm e2e
pnpm build
```

必须满足：

- 测试、类型检查、ESLint 和生产构建全部通过。
- 生产模式 E2E 无失败用例。
- 1440×900、1280×800、1024×768、768×1024、390×844 无横向溢出、裁切或不可点击控件。
- 移动端侧栏打开后焦点进入主操作，Escape 关闭后焦点返回触发按钮。
- 流式 fixture 在 `done` 前至少产生两次可见更新。
- 用户可见区域没有旧品牌文案。

## 发布步骤

1. 记录当前线上 Web 镜像摘要、Git 提交和环境变量，确认可直接回切。
2. 备份部署配置。数据库结构未变化，不要求为本次前端发布执行迁移。
3. 从已通过门禁的提交构建新 Web 镜像，保持现有 API、鉴权和代理配置不变。
4. 先部署到预发布环境，完成下方冒烟验收后再替换生产 Web 实例。
5. 发布后观察前端错误率、SSE 首 token 时间、路由失败率和设置保存失败率。

生产环境必须提供 `MARKDOWN_IMAGE_PROXY_SECRET`，并确保反向代理关闭 SSE 响应缓冲和不必要的压缩聚合。

## 发布后冒烟验收

1. 打开首页，确认品牌、数据集选择、更多设置、输入框和发送按钮可见。
2. 连续进入对话、知识库、评测与分析、系统页面，确认没有完整 document navigation，侧栏位置保持。
3. 发起一次真实对话，确认 `done` 前至少出现两次答案增量；停止和恢复不产生重复消息。
4. 打开设置页，验证搜索、五组导航、高级折叠、未保存计数、保存成功和保存失败提示。
5. 在 390×844 打开侧栏，检查遮罩、关闭按钮、键盘焦点和 Escape 返回。
6. 打开知识库、历史和图谱代表页面，确认无控件遮挡、横向滚动和正文按钮覆盖。

## 回滚触发条件

出现以下任一情况应回滚 Web：

- 受保护路由无法进入，或导航产生完整页面刷新循环。
- SSE 在 `done` 前没有可见增量，或停止、恢复产生重复消息。
- 设置无法读取或保存，且确认不是后端服务故障。
- 主视口出现大面积空白、不可关闭弹层或关键按钮被遮挡。
- 前端错误率相对发布前基线显著上升。

## 回滚步骤

1. 停止继续放量，不修改数据库和业务数据。
2. 将 Web 服务切回发布前记录的镜像摘要或 Git 提交；API、Worker、数据库和对象存储保持原版本。
3. 若必须通过 Git 生成回滚提交，按从新到旧的顺序 `git revert` 本次前端重构提交，不使用 `git reset --hard`，不删除未跟踪文件。
4. 重新构建并部署 Web，确保旧静态资源和新静态资源不混用。
5. 重复首页、四组导航、真实流式对话和设置读取四项冒烟检查。
6. 记录触发原因、失败请求 ID、浏览器控制台错误和回滚后的恢复时间。

由于本次没有数据库迁移和 SSE 事件破坏性变更，回滚只需要替换 Web 构建产物；用户数据、索引和会话记录无需恢复。

## 已知说明

- 发布验收以生产构建为准。本机开发模式完整 E2E 曾受 Next HMR chunk 偶发语法错误影响，生产模式 E2E 未复现。
- 不同反向代理可能改变 SSE 首包和 chunk 间隔，正式环境仍需执行一次真实流式冒烟。
- 本分支不自动创建 Issue、推送远端或发布镜像，远端发布需由维护者在确认提交范围后执行。
