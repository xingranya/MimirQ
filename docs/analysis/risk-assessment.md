# 风险评估

| 风险 | 影响 | 控制措施 |
| --- | --- | --- |
| SSE 实际缓冲点未确定 | 用户仍看不到增量回答 | 先记录 headers、首 token、后续 token 和渲染时间，再按证据修复 |
| App Router 双路由树 | 改壳层可能造成重复挂载 | 只在共享 `AppFrame`、模板和滚动重置处做最小修改 |
| 15 个设置分区权限不同 | 重组后可能越权或丢入口 | 继续复用权限 gate，分组只改变展示层 |
| 品牌替换误伤内部标识 | API、缓存或迁移不兼容 | 只替换用户可见文案和资源，扫描测试中排除内部键 |
| 窄屏控件重叠 | 关键操作不可点击 | 固定控件尺寸、目标视口截图和 e2e 断言 |
